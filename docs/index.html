Small app, short path from screen to share

GIFt does one job. It records what you point it at and hands you a file that is ready to paste.

An area or a window

Drag a box over any part of any display, or pick one window from the menu. A window is recorded even when it moves or something covers it.

Review before saving

Trim either end and scale the recording down, with an estimate of the file size, before anything is written.

Copied, ready to paste

The saved file goes onto the clipboard as a file. Paste it into Slack, GitHub, or an email and it attaches.

GIF or MP4

GIF plays everywhere. MP4 makes much smaller files when a recording has a lot of motion.

Clicks you can see

A ring marks every click inside the recording, so viewers can follow along without guessing.

Stays on your Mac

Recordings save to a folder you choose. GIFt sends no telemetry and uploads nothing.

New: agents

Let your coding agent show you its work

Claude Code, Codex, and other agents can drive GIFt from the shell. They screenshot the screen with a measurement grid, read off the exact area that changed, record a short GIF of it, and put it in front of you.

AI apps without a shell, like Claude Desktop and the ChatGPT desktop app, connect through MCP.

Set up agents

# Where is the thing that changed?
gift screenshot --grid
{ "path": "/…/gift-1791211329847.png" }

# Record just that area for five seconds
gift record --area 120,340,800,500 --seconds 5
{ "path": "~/Movies/gift-1791211346917.gif" }

# Show it to the user
gift show ~/Movies/gift-1791211346917.gif
  1. Download and drag

    Open the DMG and drag GIFt to Applications.

  2. Grant Screen Recording

    GIFt's first window walks you through the one permission it needs.

  3. Select and record

    Choose Select Area… from the menu bar icon, drag a box, and recording starts.

  4. Stop and paste

    Press ⌘ ⎋ or the stop button, review, and paste.

Recording in under a minute

There is no account to make and nothing to configure. The defaults suit a screen recording for a bug report or a pull request.

The guide covers every option, the three permissions GIFt can use, and what each one is for.
