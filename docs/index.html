Quick start

The guide covers each step in detail.

  1. Install

    Open GIFt.dmg and drag GIFt to Applications. Open it from there.

  2. Grant Screen Recording

    The Settings window opens on first launch. Grant Screen Recording there.

  3. Select an area

    Click the menu bar icon, choose Select Area…, and drag a box. Recording starts when you let go.

  4. Stop

    Press ⌘ Esc or the stop button beside the outline. Trim and save in the review window. The file is copied to the clipboard.
